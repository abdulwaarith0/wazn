Wazn: Technical Plan

A static React site: the word list ships inside the app, progress lives in the browser, and Motion flies the letters.

Approved

How it works, in plain language

No server, no database. Wazn is a bundle of files that runs entirely in the visitor's browser.

The word list ships inside the app as TypeScript data files, so it already knows every word when it loads.

Progress is a note the browser keeps (localStorage). Collect a word and the note updates; come back and it's read back.

The animation is the heart. The app works out from the word itself which letters came from the root, draws the pattern with ف ع ل placeholders, and Motion flies each root letter in. The real word, colour-coded, replaces the moving pieces.

Components

WordAssembly the kernel · prd › Root Workshop, Intro
  1. Draw the placeholder as letter pieces with invisible joiners: pattern letters gold, ف ع ل placeholders soft gold.
  2. Each root letter flies from its tile on an arc (Motion animate()), staggered; the placeholder is pushed out at ~60%; landing squash, ink ripple, standalone → joined cross-fade.
  3. Real word fades in as normal text, colour-coded, with a slight settle; the meaning rises in.
  4. Reduced motion: a simple fade. Waits for fonts before measuring. Returns a promise when done.
Workshop + PatternTile prd › Root Workshop, Greyed-Out Patterns
Root letters on top, stage in the middle, a tile per pattern. No word for this root → greyed; tap shakes and explains. Real tile → WordAssembly, then collect if new. Taps ignored mid-animation.
RootsScreen, RootTile, ModeSwitch prd › Roots Screen, Switch
Tiles: locked (tap explains the unlock), unlocked (e.g. 4 / 8), sealed (gold seal). Beginner/Grammar switch. Ways into Collection and Quiz.
Intro prd › Intro
WordAssembly with وَزْن on first open; tap skips; sets introSeen; the logo replays it.
CollectionScreen, WordCard prd › Collection
Grouped by root in unlock order, seals in the group header; each card: colour-coded word, meaning, source pattern. Empty-state invitation.
Moments prd › Collecting, Unlocking and Seals
RewardBurst (word collected), UnlockMoment (new root slides in), SealMoment (wax-seal stamp), CompletionMoment (all sealed).
QuizScreen Phase 2 · prd › Quiz
Opens after 3 words. Alternates Find the root (tap 3 letters from a tray of 6) and Build the word (drag letters into slots with Motion drag). Correct → WordAssembly; wrong → correct answer animates in.
AudioButton + useAudio Phase 3 · prd › Audio
Plain audio files from public/audio. Auto-plays only the first time a word forms; no icon without a file.

Data

Content (read-only, in the code): Root, Pattern, Word. A word stores its vowelled Arabic and a roles string, one character per letter:

كَاتِب  →  roles "rprr"  →  فَاعِل

The placeholder is derived, never stored: swap each r letter for ف, ع, ل in order. A test checks every word's r letters spell its root.

Progress (in the browser): localStorage["wazn:progress:v1"] = collected word ids, mode, introSeen, heard (Phase 3). Saved on every change, read on start.

Derived, never stored: unlocked roots (first root + each next one after 3 words from the previous), seals (every available word collected), counts.

Look and feel

papercard ink · root lettersgold · pattern letters, seals soft gold · placeholders

Amiri for Arabic (≈84px forming word), Inter for English. Calm, spacious layout; the playfulness lives in the motion (springs with a little overshoot). Thin gold rules, a geometric border on the stage, an SVG wax seal. Light theme only.

Where it breaks, and what happens

Font not loaded when measuring
Wait for document.fonts.ready; Amiri is bundled.
localStorage blocked or full
Keep progress in memory for this visit; the app still works.
Corrupted or old saved data
Ignore it and start fresh.
Rapid tapping mid-animation
Pattern taps ignored until the word lands.
Safari joins colour-coded letters differently
Checked in Chrome only. Test on Safari early; fallback: one colour on Safari.

Decisions and the open question

  • Yours: Vite + React + TS + Tailwind; Motion; Vercel live link.
  • Derived by me: TS pinned to 6.0, bundled fonts, Inter, light only, no router in Phase 1, seals follow the current word set, taps ignored mid-animation.
  • Commits: one file per commit, own message, no AI attribution.
  • Your useful unknown (animation): how a letter flies between two unrelated places on the page. Build-time experiment: try Motion's layoutId on one letter vs the hand-measured flyers, and compare smoothness and joining.
